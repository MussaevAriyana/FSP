# ФСП Карьера

Платформа подбора ИТ-специалистов для Федерации спортивного программирования. Кандидат получает категорию (специализация × грейд) по тесту, работодатель сам находит его в категоризированной базе и отправляет приглашение с вилкой зарплаты; контакты кандидата раскрываются только после его согласия.

## Быстрый старт

```bash
export SECRET_KEY=$(python3 -c "import secrets;print(secrets.token_hex(32))")
docker compose up --build          # http://localhost:8000, Swagger: /docs
```

Без Docker: `pip install -r requirements.txt && python3 scripts/seed.py && python3 run.py`

Демо-входы (пароль `Demo12345`): `demo.candidate@fsp-demo.ru`, `demo.employer@fsp-demo.ru`, `moderator@fsp-demo.ru` (кабинет модератора прокторинга). Тест идёт под прокторингом — нужны веб-камера и разрешение браузера. Новый модератор: `python3 scripts/create_moderator.py <e-mail> <пароль>`.

Сведения о ФСП в подвале сайта и их контакты — в `data/fsp_about.json` (пустые поля не показываются).

## Что внутри

- `app/` — приложение (Flask, SQLite, Pydantic): API с автогенерацией OpenAPI, генератор заданий (≈80 семейств, уровни 1–5), прокторинг и модерация, каталог из 159 технологий, матчинг, интеграция с реестром ФСП, резюме в сервисе и PDF, тренировка, награды, кошелёк и платные услуги (демо-оплата), SPA в `app/static/`.
- `scripts/seed.py` — демо-данные через настоящий конвейер; `scripts/validate.py` — процедура валидации; `scripts/simulate.py` — модель синтетического кандидата.
- `tests/` — 35 сквозных тестов: `python3 tests/runner.py`.
- `docs/DOCUMENTATION.md` — полная документация: соответствие ТЗ, архитектура, механика тестов и устойчивость к передаче заданий, матчинг, валидация и её результаты, интеграция с ФСП, API, библиотеки, запуск.

Код открыт; зависимости только с открытыми лицензиями.


## Что нового (сборка 2026.10.11-2)
- Конструктор резюме по нормам РФ (опыт, образование, языки, ссылки, личные данные по ст. 64 ТК РФ — скрыты по умолчанию), подсказки по заполнению, PDF.
- Отклик можно изменить (`PATCH /api/candidate/applications/{id}`) или отозвать (`DELETE`).
- Работодатель: резюме кандидата (`GET /api/employer/candidates/{code}/resume.pdf`), «Подробнее», «Поиск», стадии интереса в приглашениях (`PATCH` стадии), зарплата — любые числа.
- 12 специализаций, 215 технологий, витрина на главной (`/api/public/showcase`), настоящие контакты ФСП.
- Прокторинг: телефон и посторонний человек в кадре (детектор COCO-SSD подгружается из CDN; без интернета отключается молча).
- Шрифты TDA Text и JetBrains Mono (лицензии OFL в `app/static/fonts`), логотип ФСП.
- После обновления остановите старый сервер, запустите из новой папки и нажмите Ctrl+F5 (в шапке проверяется версия сборки).
